# 꼬마공룡 코코비 — 소개 웹사이트

KIGLE의 IP **코코비(Cocobi)** 와 캐릭터들을 소개하는 인터랙티브 웹사이트입니다.
스크롤하면 가운데 카드가 작아지면서 8개의 캐릭터 타일이 모여드는 줌아웃 연출로 구성되어 있어요.

## 화면 구성

| 순서 | 내용 |
|---|---|
| 첫 화면 | 코코비 가족 일러스트 + 웰컴 문구 |
| 스크롤 직후 | 코코비 로고 + 이름의 의미(용감한 코코 + 귀여운 러비) |
| 그리드 완성 | 캐릭터 타일 8개: 코코 · 러비 · 도나 · 밥 · 라라 · 벨 · 잭잭 · ETC |
| 타일 클릭 | 캐릭터 소개 페이지 `character.html?c=이름` (ETC는 나머지 친구 9명 모아보기) |

모바일(폭 991px 이하)에서는 세로로 쌓이는 레이아웃으로 바뀝니다.

## 실행 방법

정적 파일만으로 동작합니다. `index.html`을 브라우저로 열거나, 개발 서버(캐시 없음)를 띄우세요.

```bash
python scripts/serve.py        # http://localhost:5173
```

## 폴더 구조

```
index.html, character.html   페이지
css/, js/                    스타일·스크립트 (캐릭터 데이터: js/characters.js)
assets/cocobi/               페이지에서 쓰는 코코비 공식 이미지
assets/generated/            아웃트로·공유 미리보기용 보조 이미지
scripts/serve.py             개발 서버 (캐시 없음)
scripts/pack.py              친구에게 보낼 공유용 압축 파일 만들기
```
